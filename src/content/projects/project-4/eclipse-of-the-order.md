A fast-paced 2D rogue-lite engineered from scratch. 

Developed utilizing **PyGame** and completely hardcoded, this project features a highly dynamic application loop, custom in-game economic systems, and a memory-efficient state machine. It is a continuous proving ground for low-level system architecture and object-oriented programming.
